# Security Policy

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** link on this repository's Security tab.
That private channel is the supported way to report a suspected vulnerability,
exposed credential, private-data exposure, or unsafe repository access.

Do not open a public issue or discussion containing exploit details. Do not
include credentials, tokens, cookies, private keys, production data, or other
secrets in any report. If the private reporting link is unavailable, contact an
authorized Accelerate Global representative through an established private
channel and include only enough detail to arrange a secure handoff.

Please allow the maintainers time to validate and remediate the report before
public disclosure.

## Supported branch

Security fixes are accepted on `main` through pull requests that pass the
repository's required checks. Older releases and the archived historical
repository are not independently supported.
